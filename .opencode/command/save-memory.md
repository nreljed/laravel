# Save Memory

Capture curated insights, conventions, or lessons learned (avoid raw session dumps).

## Usage
/opencode command save-memory "Topic" "Content"

## Steps
1. Append to appropriate file in docs/memory/ (conventions.md, gotchas.md, lessons-learned.md, or create new)
2. Include date and context
3. Keep concise and searchable
